SOLUTION 2: NGROK WITH CREDIT CARD (Free but requires card verification)
===============================================================================

Ngrok requires credit card for TCP (but won't charge on free plan)

Steps:
1. Sign up: https://dashboard.ngrok.com/signup
2. Add card: https://dashboard.ngrok.com/settings#id-verification
3. Get authtoken: https://dashboard.ngrok.com/get-started/your-authtoken
4. Add to .env: NGROK_AUTHTOKEN=your_token
5. Run: npm start

Server will show SMS command like:
   SERVER,1,0.tcp.ngrok.io,12345,0#

Pros: Easy, works anywhere
Cons: Requires credit card, URL changes on restart (fixed with paid plan $8/mo)

SOLUTION 4: SERVEO (FREE - Command Line Tunnel)
===============================================================================

Free SSH tunnel, no signup needed:

1. Open new terminal (keep server running)
2. Run: ssh -R 8800:localhost:8800 serveo.net
3. It will show: Forwarding TCP connections from serveo.net:XXXXX
4. Use SMS: SERVER,1,serveo.net,XXXXX,0#

Pros: Completely free, no signup
Cons: Port changes each time, less reliable
